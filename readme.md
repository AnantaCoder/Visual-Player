# PyQt GUI App with MediaPipe & OpenCV

This is a desktop GUI application built with **PyQt5**, **MediaPipe**, and **OpenCV**. It features real-time computer vision capabilities such as hand tracking, face detection, or pose estimation depending on your implementation.

## 🚀 Features

- Real-time webcam access using OpenCV
- MediaPipe integration for gesture/face/pose tracking
- User-friendly GUI made with PyQt5
- Cross-platform support
- Lightweight and fast

## 🛠 Tech Stack

- Python
- PyQt5
- MediaPipe
- OpenCV
- NumPy
